# Jain Wisdom Hub (50)

i wanna make a jain kathaye web application:
Jain Kathayein Vachanalaya

जैन कथाएँ वाचनालय

It is a platform where users can read, listen to, learn, and explore Jain knowledge.

Instead of being just a website containing articles, the goal is to make it feel like a modern content platform, similar in experience to social-media/content apps, while keeping a strong Jain identity.

🎯 Main purpose

The project solves a simple problem:

There is a lot of Jain knowledge available online, but it is often difficult to discover and consume in a modern way.

Your application organizes that knowledge into one place.

A user can come to the website and:

Read Jain stories → Listen to stories → Learn Jain philosophy → Explore Tirthankars → Take quizzes → Save content → Continue reading later.
